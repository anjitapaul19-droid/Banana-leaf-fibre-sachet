# Technical Design: Banana Leaf Fibre Sachet

## 1. Project Overview
The project explores a tri-layer composite sachet made using banana leaf-based material for potential packaging applications.

## 2. Proposed Workflow
Banana leaf collection → Cleaning and preparation → Material processing → Layer formation → Layer assembly → Drying or curing, if required → Prototype evaluation.

The exact process will depend on the selected materials and fabrication method.

## 3. Proposed Layer Structure
The sachet is intended to have three layers. The final material composition and function of each layer will be documented after the design is finalised.

## 4. Testing Plan
- Strength: Assess the prototype's resistance to handling.
- Flexibility: Observe bending and folding performance.
- Moisture resistance: Evaluate its response to controlled moisture exposure.
- Usability: Check whether the prototype is suitable for its intended packaging application.

## 5. Safety and Limitations
The sachet must not be considered suitable for food contact, commercial packaging, or composting until the relevant requirements have been evaluated.

## 6. Future Development
Improve the material composition, fabrication process, durability, and practical performance based on test results.
